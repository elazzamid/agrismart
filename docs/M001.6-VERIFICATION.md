# M001.6 Farm Domain Verification

## Required checks

- Unauthenticated farm requests return HTTP 401.
- A farmer can list only their own farms.
- A farmer can retrieve only their own farm.
- A farmer cannot retrieve another farmer's farm; the API must return 404.
- Farm creation rejects an empty name.
- Farm creation preserves ownership from the authenticated context and never accepts farmer_id from the request body.
- Invalid latitude/longitude and non-positive plot areas are rejected by database constraints.

## Service contract

Farm lookup must always scope by both farm ID and authenticated farmer ID.

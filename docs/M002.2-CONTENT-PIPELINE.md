# M002.2 Knowledge Content Pipeline

## Lifecycle

```text
DRAFT → REVIEW → VALIDATED → PUBLISHED
  ↑        │          │
  └────────┴──────────┘
```

Rejected material returns to `draft`. `needs_revision` remains in `review` until a new validation decision is recorded.

## Required provenance

Every published knowledge item must have a source-backed version. The validator and validation decision are stored separately from the author and source.

## Publishing gate

Publishing is allowed only when:

1. the document is currently `validated`;
2. the document has a version;
3. that version has an `approved` validation.

The AI retrieval layer must filter to `published` documents only.

## Content policy

Actionable pesticide and fertilizer recommendations require source-backed evidence and validation. Product labels, government agricultural guidance, research/extension publications, and other authoritative references should be preferred according to the content type.

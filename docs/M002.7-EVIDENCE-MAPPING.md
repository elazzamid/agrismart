# M002.7 Evidence Mapping Contract

Diagnosis candidates must be supported by explicit symptom-to-problem mappings and published knowledge applicability.

## Rules

1. A symptom mapping points to exactly one pest or disease.
2. `weight` is a ranking signal, not a probability.
3. A candidate is never presented as a definitive diagnosis.
4. Crop applicability must be backed by a published knowledge document.
5. Actionable control instructions must come from published, source-backed knowledge.
6. Pesticide dose, interval, tank mix, PHI, and product claims require separate source/label validation.

## Response semantics

The diagnosis API returns candidates ordered by evidence score. The UI should show matched evidence and recommend additional field checks when confidence is insufficient.

# M002.4 Initial Cabai Sources

The first AgriSmart knowledge ingestion set uses Indonesian agricultural institutional sources.

## Sources

1. BPTP Sumatera Utara — *Budidaya Tanaman Cabai* (2007).
2. Direktorat Sayuran dan Tanaman Obat — *Standar Operasional Prosedur Budidaya Cabai Rawit* (2020).
3. Direktorat Jenderal Hortikultura — *Hama dan Penyakit pada Tanaman Cabai serta Pengendaliannya* (2024 page publication).
4. BPTP Jawa Barat — *Petunjuk Teknis Pengendalian Hama dan Penyakit Utama Tanaman Cabai Merah dan Tomat* (2014).

## Ingestion rule

These records are source registrations only. No dose, application interval, pre-harvest interval, tank-mix instruction, or other actionable pesticide recommendation is copied into seed data.

Content must be extracted into a versioned knowledge document, linked to its source, reviewed, approved, and published before it becomes eligible for AI retrieval.

# M002.1 Knowledge Base Schema

## Goal

Create a traceable agricultural knowledge foundation without embedding unverified agronomic recommendations in generic seed data.

## Publication flow

```text
Source
  ↓
Knowledge Document
  ↓
Version
  ↓
Validation
  ↓
Published
  ↓
AI Retrieval
```

## Core entities

- `knowledge_sources`: provenance and source classification.
- `knowledge_documents`: logical knowledge item and publication state.
- `knowledge_versions`: immutable content versions tied to a source.
- `knowledge_validations`: review decisions and validator metadata.
- `knowledge_crop_links`: crop/variety/growth-stage applicability.
- `cultivation_guides`: actionable cultivation content linked to a document.
- `fertilizers` and `fertilizer_nutrients`: product/nutrient catalog foundation.
- `active_ingredients` and `pesticides`: pesticide identity and label provenance foundation.
- `pests`, `diseases`, `weeds`: agricultural problem catalog.

## Safety boundary

The schema intentionally does not yet provide a free-form table for pesticide dose, spray interval, tank mixing, or other actionable instructions. Those recommendations require a source-backed model and validation workflow first.

## AI boundary

Only knowledge documents with `status = published` should be eligible for retrieval by the future AI layer. Draft, review, rejected, and archived content must not be treated as published guidance.
